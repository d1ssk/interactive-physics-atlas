How branch following works

The background evaluates one branch point by point. During a drag, each multivalued operation unwraps its argument continuously. When the path crosses a displayed cut, the background is redrawn on the branch selected by that crossing direction.

A branch cut is a convention for drawing a single-valued chart. The precise operation here is analytic continuation, or lifting the path to the Riemann surface. A path closed in the base plane need not close after this lift.

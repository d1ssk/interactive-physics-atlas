# Crystal Lattices and First Brillouin Zones

This visualization compares real-space primitive cells with reciprocal lattices and constructs
the first Brillouin zone as the reciprocal-lattice Wigner–Seitz cell.

Build the application with:

```bash
uv run python scripts/build_visualizations.py
```

Run its focused tests with:

```bash
uv run pytest visualizations/brillouin-zones/tests
```

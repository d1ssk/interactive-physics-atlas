Finite-type criterion

When is a Dynkin diagram valid?

Cartan entries. The diagonal entries are 2; off-diagonal entries are non-positive integers; and Aij vanishes exactly when Aji does. Single, double, and triple bonds have AijAji equal to 1, 2, and 3.

Finite-type test. There must be positive integers di such that D A is symmetric for D = diag(di), and this symmetric matrix must be positive definite. This is the complete algebraic criterion used by the Python catalogue.

Diagram shape. Each connected component is a tree from one of the A, B, C, D, E, F, or G families. It has no cycles, at most one multiple bond, and no node of degree greater than three. These quick rules are necessary, but the precise branch lengths and bond placement must also match a finite family.

Disconnected diagrams. Every connected component must pass the finite-type test. The result then represents a semisimple direct sum and is shown as a product of diagram and compact-group labels.

How to play and what counts as valid

Add node creates simple roots. Connect joins two selected nodes with the chosen bond. A new multiple bond points to the second node; select it and use Reverse arrow to change the root-length ordering.

A connected result must be one of An, Bn, Cn, Dn, E6,7,8, F4, or G2. Disconnected valid components are recognized as semisimple products. The construction limit is rank eight.

Keyboard: Delete removes the selection; Escape clears it; Ctrl/Cmd+Z undoes and Ctrl/Cmd+Shift+Z redoes.

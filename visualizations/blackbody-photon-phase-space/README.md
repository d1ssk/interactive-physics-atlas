# Blackbody photon phase space

Browser-native visualization of ideal blackbody photon distributions in frequency-direction
phase space. The Earth component fills the full sky at 250--300 K; the solar component occupies
the nominal solar disk at 1 AU and has a temperature of 5400--6200 K.

Each point represents equal photon number sampled from
$\mathrm dN/(\mathrm dV\,\mathrm d\Omega\,\mathrm d\ln\nu)$. The application deliberately has
no brightness encoding. Linear radius is the default; logarithmic radius uses the same
$1.5\,\mathrm{PHz}$ outer frequency so the overall point-cloud size remains comparable.

The model is an idealized phase-space comparison, not a terrestrial radiation-budget model.
Absorption, reflection, atmospheric transfer, surface geometry, and occultation are omitted.

# Lorentz Transformation

A browser-native 1+1-dimensional Minkowski-diagram visualization. It compares the coordinates
assigned to one event by two inertial frames and allows either frame to be shown with orthogonal
axes. Optional constructions display time dilation and length contraction as hyperbolic rotations
that preserve proper time or proper length.

Conventions: `c = 1`, coordinates `(x, ct)`, metric signature `(+,-)`, and positive `beta` means
that `S'` moves in the positive spatial direction of `S`.

# ディンキン図形ビルダー

## 数学的背景

ディンキン図形は、単純ルートの集合がもつ二体間の幾何を表します。各ノードは1つの単純ルートに
対応します。辺はカルタン行列の非対角成分の積 $A_{ij}A_{ji}$ を表し、多重辺上の矢印は短い
ルートと長いルートを区別します。

有限結晶型ディンキン図形は有限次元複素半単純リー代数を分類します。連結図形は単純因子を表し、
非連結図形はそれらの直和を表します。

## 試してみること

1. 4個のノードと3本の単辺から $A_4$ を構成します。
2. $A_4$ に分岐を1つ追加し、$D_4$ と認識されるまでノードを並べ替えます。
3. 二重辺の矢印を反転して $B_3$ と $C_3$ を比較します。
4. 2個のノードを三重辺で結び、$G_2$ を構成します。
5. 非連結な $A_2\times A_1$ を作り、半単純代数としての分類を確認します。
6. チャレンジモードを選び、標準配置を使わずに例外型図形を再構成します。

## 規約と制限

規約は

$$
A_{ij}=\langle\alpha_i,\alpha_j^\vee\rangle
$$

です。二重辺または三重辺の矢印は、短い単純ルートの方向を指します。分類はノードの位置と番号に
依存しません。エディターは全階数8までの有限結晶型
$A_n$, $B_n$, $C_n$, $D_n$, $E_6$, $E_7$, $E_8$, $F_4$, $G_2$
を認識します。

階数の上限はインターフェース上の範囲であり、古典系列に数学的な上限があるという意味では
ありません。別名 $B_2=C_2$, $D_3=A_3$, $D_2=A_1\times A_1$ は、区別できない図形を
重複させずに表示します。

### 有限型の判定条件

一般化カルタン行列が有限結晶型ディンキン図形を定める条件は次のとおりです。

1. $A_{ii}=2$、非対角成分は非正整数であり、$A_{ij}=0$ と $A_{ji}=0$ は同値です。
2. $D=\operatorname{diag}(d_i)$ としたとき $DA$ が対称となる正整数 $d_i$ が存在します。
3. 対称行列 $DA$ は正定値です。

3番目の条件が有限型をアフィン型および不定型の一般化カルタン行列から区別します。図形としては、
有限型の各連結成分は $A$, $B$, $C$, $D$, $E$, $F$, $G$ のいずれかの木です。閉路をもたず、
次数4以上のノードをもたず、多重辺は高々1本です。ただし、これらの形状条件だけでは十分ではなく、
枝の長さ、多重辺の位置、矢印の向きも分類された系列のいずれかと一致する必要があります。

古典系列については、標準的なコンパクト群の記法も表示します。

- $A_n$: $SU(n+1)$
- $B_n$: $SO(2n+1)$ とその単連結被覆 $\operatorname{Spin}(2n+1)$
- $C_n$: $Sp(n)$
- $D_n$: $SO(2n)$ とその単連結被覆 $\operatorname{Spin}(2n)$

これらのラベルは対応するリー代数をもつコンパクト群を表しますが、ディンキン図形だけでは群の
大域的な形は決まりません。

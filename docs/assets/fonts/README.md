# Self-hosted body fonts

The published site uses locally hosted Source Serif 4 for English prose. Japanese prose uses a
system-font stack while a replacement family is being selected.

The source TTF files and their license texts were obtained from the corresponding directories in
the official [Google Fonts repository](https://github.com/google/fonts). The WOFF2 files were
converted without subsetting so that scientific notation and the full Japanese character set
remain available. The family is distributed under the SIL Open Font License included in its
directory.
